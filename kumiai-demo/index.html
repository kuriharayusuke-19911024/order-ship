お試し版（GASにはつながっていません）データはこの画面の中だけで、再読み込みすると空に戻ります。下のボタンで立場を切り替えて、流れを確かめられます。
使い方（空の状態から始めます）
  1. 栗原（事務局）を押す →「設定」→「メンバーと暗証番号」の＋追加で、カワヨの担当者と農家を登録（農家は「いつもの積み込み」も選ぶ）。同じ画面で品目のkg単価と組合手数料も入れておく
  2. 登録した人のボタンが上に増えます。農家を押す →「出せるロール」で品目とロール数を登録
  3. カワヨの担当者を押す →「発注する」で品目とkgを入れる（ロール数が自動で出ます）
  4. 事務局に戻る →「＋農家に振り分け」で農家とロール数を決める
  5. カワヨで候補日を入れる → 農家で日付をタップして確定 → カワヨで実際の納品kgを入力
  6. 事務局の「伝票」で、カワヨへの請求書と農家ごとの支払明細書を月締めで発行 → カワヨの「請求書」、農家の「支払明細」タブに届きます
事務局（碓永さん・栗原）
発注を見て農家に振り分け。全農家の在庫・精算・伝票の発行と入金／支払の管理・設定（品目、1ロールの重さ、kg単価、手数料、伝票に載せる住所や振込先）
カワヨ
品目とkgで発注 → 引き取り候補日を入れる → 実際の納品kgを入力 → 組合からの請求書を確認
農家
出せるロール数を登録 → 候補日から都合のいい日を選ぶ。積み込み（農家が積む／カワヨがフォークで積む）もここで選べます → 組合からの支払明細書を確認。ほかの農家の数字は見えません

伝票の金額：請求書＝納品kg×kg単価、支払明細書＝納品kg×（kg単価−組合手数料）、どちらも消費税は設定の税率で計算。本番では各自が名前と4桁の暗証番号でログインし、振り分け・日程確定・伝票の発行がLINEに通知されます。
